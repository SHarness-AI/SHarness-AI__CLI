SHarness playground: sharness-ai in Pyodide and under a real Linux kernel

Two runtimes in this tab. Pyodide is Python in WebAssembly: install the dev wheel, then hash, check and translate policies; with no kernel, run and hello refuse. Linux is Alpine with a Landlock kernel in v86: a shell where every sharness-ai run is enforced by the kernel, on its child. A Boundary for the child, a Setting for the shell.
